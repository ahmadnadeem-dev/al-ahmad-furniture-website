# Al Ahmad Furniture — Handcrafted Furniture from Chiniot

Store website designed and built by **Ahmad Nadeem** for Al Ahmad Furniture, makers of handcrafted Chinioti furniture.

This repository holds the site's homepage as a single self-contained file: hero, shop-by-room collections (Living Room, Bedroom, Dining, Home Office, Sofa Sets, Chinioti Swings), bestsellers, the craft process, customer reviews and showroom details — with ordering on WhatsApp.

## Highlights

- Handcrafted solid-wood furniture from Chiniot, Punjab
- Shop by room: Living Room · Bedroom · Dining · Home Office · Sofa Sets · Chinioti Swings
- WhatsApp ordering built into the product cards
- Showroom: Main Jhang Road, Chiniot
